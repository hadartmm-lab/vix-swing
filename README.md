# VIX Swing Live — 2–3 Days

אפליקציית Streamlit שמושכת אוטומטית VIX, VIX9D, VIX3M, S&P 500 ו-Nasdaq 100 דרך Yahoo Finance/yfinance, מחשבת EMA5/EMA10/EMA20, RSI ושינויי 1/2/5 ימים, ומחזירה LONG / SHORT / WAIT לטווח 1–3 ימי מסחר.

## הרצה מקומית
```bash
pip install -r requirements.txt
streamlit run app.py
```

## פריסה ל-Streamlit Community Cloud
1. העלה את התיקייה ל-GitHub.
2. ב-Streamlit Community Cloud בחר את ה-repository ואת `app.py`.
3. לאחר Deploy תקבל URL קבוע שאפשר לשמור במסך הבית באייפון.
