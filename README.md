# VIX Tactical v11.4 — Logic Review

## העלאה ל-Streamlit
חלץ את ה-ZIP. העלה את app.py ואת requirements.txt לאותה תיקייה במאגר שלך.
הקובץ הראשי להפעלה הוא app.py. אפשר להעלות גם את .streamlit/config.toml.
אין צורך להעלות את tests או את קובצי ההסבר להפעלת הבוט.

הגרסה מתוקנת ונבדקה מבחינת לוגיקה והרצת ממשק עם נתונים סינתטיים.
אין כאן הוכחת שיפור בתשואה או באחוזי ההצלחה, ואין בק-טסט היסטורי.
קרא REVIEW_HE.md לפירוט ממצאים, שינויים ומגבלות.

הכיוון נגזר ממשפחת מדדי VIX. QQQ משמש לשכבת תזמון בלבד.
1H הוא נר מקור סגור; 4H הוא מקטע סשן כולל מקטע אחרון קצר;
הכינוי 12H נשמר לתאימות, אך הוא בפועל סיכום סשן יומי, לא נר 12 שעות.
הספים והמשקלים הם היוריסטיים, לא הסתברויות מכוילות.
